# Pointer Operations in C

## Project Description

A simple C program that demonstrates the use of pointers. The program uses pointers to swap two numbers and display their memory addresses.

## Features

- Swap two numbers using pointers
- Display memory addresses
- Demonstrate pointer usage

## Technologies Used

- C
- Pointers
- Functions

## How to Run

Compile and run the `pointer_operations.c` file using a C compiler.
